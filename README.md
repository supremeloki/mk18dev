# MK18DEV — ده روایت پورتفولیو

ده نسخه کامل و مستقل از پورتفولیو. **همه از یک داده واقعی** (خوانده‌شده از مخازن)
ساخته شده‌اند؛ آنچه فرق دارد، سؤالی است که هر کدام جواب می‌دهند.

| # | روایت | سؤالی که جواب می‌دهد | مناسب مخاطب |
|---|---|---|---|
| 01 | معمار | این آدم چه ساختارهایی می‌سازد؟ | برنامه‌نویس |
| 02 | ایمان | این حرف‌ها قابل راستی‌آزمایی است؟ | داور فنی |
| 03 | محصول | چه چیزهایی کار می‌کنند؟ | سرپرست فنی |
| 04 | جریان | داده چگونه به تصمیم می‌رسد؟ | مهندس داده |
| 05 | عمیق | داخل یک سیستم چه هست؟ | داور کد |
| 06 | داده خام | اعداد چقدر دقیق‌اند؟ | داده‌شناس |
| 07 | خط زمان | چگونه رشد کرده؟ | مدیر پروژه |
| 08 | شواهد | هر مهارت با چه اثباتی؟ | مصاحبه‌گیر |
| 09 | روایت | داستان چیست؟ | عمومی |
| 10 | جمع‌بندی | همه‌چیز کجاست؟ | هر کس |

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید. نیازی به سرور نیست.

## فنی

- HTML/CSS/JS خالص — بدون فریم‌ورک، بدون CDN، بدون فونت وب
- کاملاً RTL با تایپوگرافی فارسی
- هر نسخه یک فایل مستقل زیر ۱۲ کیلوبایت
- رعایت `prefers-reduced-motion`

## داده

اعداد از شمارنده‌های زیر آمده‌اند، نه از روایت:

- ۴۲٬۱۲۷ خط پایتون در چهار مخزن اصلی
- ۷۵ ماژول منبع (۳۰ / ۲۶ / ۱۹ / ۲)
- ۶٬۵۲۶ کامیت در ۷۴ مخزن
