# ده مدل پورتفولیو — MK18DEV

ده طرح متفاوت برای پورتفولیو، همه با HTML/CSS/JS خالص — بدون هیچ فریم‌ورک، بدون CDN، بدون وابستگی خارجی.

| # | مدل | ویژگی |
|---|---|---|
| 01 | `01-glassmorphism` | کارت‌های شیشه‌ای شناور روی هاله رنگی |
| 02 | `02-blueprint` | کاغذ مهندسی با شبکه و شماره‌گذاری |
| 03 | `03-swiss` | تایپوگرافی بزرگ و خطوط سخت |
| 04 | `04-terminal` | پنجره bash با اسکن‌لاین |
| 05 | `05-cyberpunk` | نئون، گلیچ و کلیپ‌پث |
| 06 | `06-paper` | مینیمال روشن با تایپوگرافی کلاسیک |
| 07 | `07-isometric` | صحنه سه‌بعدی دست‌ساز با جعبه‌های SVG |
| 08 | `08-dashboard` | پنل‌های KPI، جدول و شاخص |
| 09 | `09-bento` | شبکه نامتقارن سلولی |
| 10 | `10-aurora` | canvas با ذرات متصل و گلاس بلور |

## ساختار

```
index.html          ← گالری مقایسه‌ای همه مدل‌ها
assets/             ← فاوآیکون SVG
_preview/           ← اسکرین‌شات هر مدل
0N-<name>/
  index.html        ← همان مدل به‌صورت مستقل و تک‌فایلی
```

## ویژگی‌ها

- کاملاً RTL با تایپوگرافی فارسی
- بدون فونت وب، بدون CDN، بدون وابستگی
- هر مدل یک فایل مستقل زیر ۲۵ کیلوبایت
- واکنش‌گرا با بازسازی در موبایل
- رعایت `prefers-reduced-motion` در مدل متحرک

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید. نیازی به سرور نیست.
